Reusable patterns

Metric card, project form, project table with mobile card equivalent, labelled bar chart, selected navigation item, and accessible modal are demonstrated in the main screens. Figma contains linked component instances.

Responsive & interaction specification

Desktop ≥1024 px: sidebar, three KPI columns and full table. Tablet 768–1023 px: horizontal navigation, two KPI columns. Mobile <768 px: collapsible menu, single-column content and project cards.

Main flow: Overview → Projects → Project detail → Analytics → Settings → Overview (six transitions). Navigation uses a 250 ms fade/slide. Modal enters in 200 ms. Reduced-motion preference disables animations. Modal supports Escape, Cancel, validation and focus return.

This is a local sample prototype. No server, payments or real account changes. Project creation and settings update the in-memory demo only.
