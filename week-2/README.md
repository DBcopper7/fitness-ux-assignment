## Typography
| Role | Size / line height | Weight |
|---|---|---|
| Display | 32 / 40 px | Bold |
| Title | 24 / 32 px | Bold |
| Heading | 20 / 28 px | Bold |
| Body | 16 / 24 px | Regular |
| Label | 14 / 20 px | Bold |
| Caption | 12 / 18 px | Regular |

## Palette and contrast
| Use | Foreground | Background | Ratio |
|---|---|---|---|
| Primary text | #172033 | #FFFFFF | 16.27:1 |
| Secondary text | #475569 | #FFFFFF | 7.58:1 |
| Card text | #172033 | #F1F5F9 | 14.85:1 |
| Secondary card text | #475569 | #F1F5F9 | 6.92:1 |
| Social button | #FFFFFF | #5B21B6 | 8.98:1 |
| Shop button | #FFFFFF | #115E59 | 7.58:1 |
| Input boundary | #64748B | #FFFFFF | 4.76:1 |
| Error text | #B91C1C | #FFFFFF | 6.47:1 |

Ratios use sRGB relative luminance. Normal text pairs exceed 4.5:1; input boundaries exceed 3:1.
WCAG reference: https://www.w3.org/TR/WCAG22/

## Spacing
4 px base: 4, 8, 12, 16, 24, 32, 48. Screen padding 20 px; card padding 16 px; section gap 16 px; card radius 12 px.

## Accessibility
Visible labels, text-based selection states, strong contrast, alt-text input for social posts and 48 px button heights. Implementation should support logical reading order, screen-reader semantics, text scaling, visible keyboard focus and reduced motion. Static mockups do not establish complete WCAG conformance.

## Scope
Editable design mockups with illustrative vector artwork and sample content. Payment, shopping and chat functionality are not implemented.
